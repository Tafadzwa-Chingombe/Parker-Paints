# Image Shot List — Parker Paints

Drop your photos into this folder using **exactly** these filenames
(lowercase, `.jpg`). Until a photo exists, the site shows the soft blue
gradient placeholder automatically, so nothing breaks if you upload in stages.

**Recommended:** JPG, under 300 KB each. Product shots square (800×800 px or
larger), scene photos landscape (1600 px wide).
